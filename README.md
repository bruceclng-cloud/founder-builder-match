# Founder Builder Match

Founder Builder Match is an open-source project exploring a fair matching platform for founders and unemployed or underemployed builders.

The core idea is simple: match serious founders with credible builders, then let both sides test fit through a scoped, paid 7-day trial sprint. The trial is not the whole product. It is the trust mechanism that makes the match fair, practical, and less exploitative.

## Why This Exists

Two waves are happening at the same time:

- more people are trying to build startups or software-enabled businesses
- more skilled builders are unemployed, underemployed, or looking for meaningful work outside traditional hiring

Existing options tend to fall into awkward categories:

- generic networking
- unpaid speculative work
- expensive contractor hiring
- vague co-founder matching
- job boards that do not fit early startup collaboration

This project asks whether a better system can exist: one where both founders and builders are treated as customers, matching is based on proof and seriousness, and short trials create real evidence before longer commitments.

## Product Thesis

The platform should help:

- founders find credible builders for specific needs
- builders find serious founder opportunities without unpaid labor
- both sides test collaboration through fair paid trial sprints
- builders collect verified proof-of-work
- founders make progress without committing too early to a hire or co-founder relationship

## MVP Shape

The first version should prove one thing:

> Can we create useful matches between serious founders and credible builders?

The initial matching signals are:

- founder need: what skill or outcome the founder needs
- builder proof: GitHub, code samples, portfolio, shipped projects, resume, or LinkedIn
- founder seriousness: budget, project clarity, timeline, and willingness to run a paid trial

After a promising match, the platform supports a 7-day paid trial sprint.

## Trial Sprint Principles

- No unpaid speculative work
- Founder pays a trial stipend
- Platform takes a small percentage, initially modeled as 10%
- Builder sets a minimum acceptable trial rate
- Platform recommends fair price ranges by project type
- Milestones are judged against the original brief and evidence, not founder mood
- Builders receive proof-of-work records even if the relationship does not continue
- Equity and co-founder legal agreements are out of scope for the MVP

## Current Status

This repository currently contains planning documents. The next milestone is a lightweight prototype for:

1. founder onboarding
2. builder onboarding
3. match recommendation
4. trial sprint brief
5. proof-of-work record

See [docs/MVP_SPEC.md](docs/MVP_SPEC.md) for the build plan.

## Open Source Direction

This project is intended to be public and contributor-friendly. The early open-source focus is to build transparent matching, fair trial workflow, and proof-of-work primitives that other startup communities, local founder groups, and builder communities can inspect or adapt.
