# Roadmap

## Current Phase: Open Prototype

Goal: prove the core workflow in public before building payments, escrow, or legal workflows.

### Milestone 1: Static MVP Prototype

- Founder intake
- Builder profile and proof display
- Match scoring with visible reasons
- Trial sprint brief preview
- Builder proof-of-work record preview
- Local draft persistence
- JSON match packet export

Status: complete

### Milestone 2: Validation Sprint

- Interview 10 founders
- Interview 10 builders
- Run concierge matching with real users
- Test pricing ranges and builder minimums
- Collect feedback in public GitHub issues

Status: in progress

### Milestone 3: Functional Web App

- Persist founder and builder profiles
- Save match results
- Save trial sprint briefs
- Save proof-of-work records
- Add authentication only when needed

Status: planned

### Milestone 4: Trust and Safety

- Add privacy review
- Add clear moderation policy
- Add payment risk notes
- Define dispute workflow
- Add security tests around private profile data

Status: planned

### Milestone 5: Payment Pilot

- Test payment flow with a small pilot group
- Keep equity and co-founder legal agreements out of scope
- Validate platform fee model
- Validate builder proof-of-work usefulness

Status: planned

## Non-Goals For Now

- Equity handling
- Legal co-founder agreements
- Fully automated AI approval
- Complex dispute arbitration
- Large-scale social network features
