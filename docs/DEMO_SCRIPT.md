# Demo Script

Use this when showing the prototype to a founder, builder, or potential contributor.

Hosted demo:

https://bruceclng-cloud.github.io/founder-builder-match/

## 5-Minute Walkthrough

### 1. Start With The Problem

Say:

> This is a prototype for matching people hiring for early projects with people looking to be hired or trialed. The goal is not free work. The goal is a fair paid 7-day trial that tests fit and creates proof-of-work.

### 2. Load A Scenario

Pick one demo scenario:

- Full-stack MVP for tutor booking
- AI operations proof-of-concept
- Design-led landing page and waitlist

Ask:

> Does this feel like a realistic hiring/getting-hired situation?

### 3. Show The Match

Open the Matches tab.

Point out:

- score
- skill fit
- price fit
- proof strength
- founder seriousness
- timezone fit

Ask:

> Are these the right signals, or are we missing something important?

### 4. Show The Trial Sprint

Open the Trial sprint tab.

Point out:

- trial type
- acceptance criteria
- evidence required
- stipend
- platform fee
- builder payout

Ask:

> Would this feel fair enough to try for 7 days?

### 5. Show Proof-Of-Work

Open the Proof record tab.

Ask:

> If the trial ended here, would this record be useful enough for the builder?

### 6. Export The Summary

Use the share summary or JSON packet.

Ask:

> If I sent you this summary before a call, would you understand the opportunity and the risks?

## Feedback Questions

- What part is immediately clear?
- What part is confusing?
- What feels unfair to the founder?
- What feels unfair to the builder?
- What would make this trustworthy enough to try?
- Would you use this as hiring infrastructure, a job-search tool, or neither?
