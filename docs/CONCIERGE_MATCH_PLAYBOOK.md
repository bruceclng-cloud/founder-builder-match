# Concierge Match Playbook

## Purpose

Run the first founder-builder matches manually before building a full marketplace.

## Inputs

### Founder

- project summary
- skill needed
- budget range
- 7-day outcome
- timeline
- timezone
- market evidence
- relevant links

### Builder

- skills
- minimum 7-day trial rate
- timezone
- availability
- proof links
- preferred opportunity type

## Matching Rules

Score matches using:

- founder need against builder skills
- founder budget against builder minimum
- builder proof completeness
- founder seriousness
- timezone compatibility

## Manual Match Message

Use this structure:

```text
I think this may be a fit because:

1. [skill fit]
2. [budget/minimum overlap]
3. [proof signal]
4. [timezone or availability fit]

Suggested 7-day trial:
[small scoped outcome]

Open questions:
[risk or missing info]
```

## After the Introduction

Ask both sides:

- Did the match feel relevant?
- What was missing?
- Was the proposed trial fair?
- Was the price range acceptable?
- Would you continue?

## Record Outcome

Use:

- GitHub issue with `research` label
- private notes for sensitive details
- public summary without personal data
